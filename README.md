# 数学Aラボ

数学Aの授業で使える、**さわって・動かして・見てわかる** Webアプリです。
`index.html` 1ファイルだけで動きます（インストール不要）。見た目は「分子ラボ3D」とそろえた方眼ノート風です。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/mathematics-a/

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari）で開く
2. 上のタブで分野をえらび、左の一覧から画面をえらぶ
3. まん中のステージで点をドラッグしたり、右のボタン・スライダーを動かしたりする
4. 右の「ポイント」「くわしく」で説明を読む。「⛶ 全画面」でプロジェクター用の大きな表示

URL の最後に `#route` のように付けると、その画面を開いた状態のリンクになります。

## できること

| 分野 | 画面 | 体験できること |
|---|---|---|
| 場合の数 | 集合とベン図 `#venn` | A・B（○の倍数）を変えると数が動いて入れかわる。∩・∪・補集合・ド・モルガンを色で確認 |
| | 順列 `#perm` | 玉を席にならべるアニメーション、樹形図、重複順列、円順列（回すと同じになる様子） |
| | 組合せ `#comb` | 円周上の点をタップしてえらぶと図形ができる。r! 通りのならべ方が1組になる。全部の組を一覧 |
| | パスカルの三角形 `#pascal` | タップで上の2つの和を表示。二項定理の係数、奇数をぬるとシェルピンスキーの三角形 |
| | 最短経路 `#route` | 指でなぞって道をつくる。交差点に道の数を書きこむ。×（通れない点）もおける |
| | ○と仕切り `#dupc` | 仕切りをドラッグしてりんごを分ける（重複組合せ）。全員1個以上にも対応 |
| 確率 | 2つのサイコロ `#dice2` | 36マスの表に色がつく。余事象、実際にふって割合をくらべる |
| | 大数の法則 `#lln` | ×100・×1000 で試行。何本も線をかいて確率に近づく様子 |
| | 反復試行 `#binom` | ゴルトンボードで玉を落とす。箱をタップすると ₙCₖ pᵏ(1−p)ⁿ⁻ᵏ を計算 |
| | 条件付き確率 `#cond` | 1000人の図と面積図。病気の検査・不良品・天気予報の例 |
| 図形の性質 | 三角形の五心 `#centers` | 頂点をドラッグ。外心・内心・重心・垂心・傍心・オイラー線 |
| | 角の二等分線と比 `#bisector` | AB：AC と BD：DC の帯グラフがいつもそろう。外角の二等分線も |
| | チェバとメネラウス `#ceva` | 点や直線を動かしても比のかけ算は 1。「読む順」をアニメーションで |
| | 円周角と円 `#inscribed` | 円周角の定理・内接四角形・接弦定理 |
| | 方べきの定理 `#power` | PA×PB と PC×PD を長方形の面積でくらべる。接線 PT² も |
| | 多面体 `#poly` | 正多面体・サッカーボールなどを回して、頂点・辺・面を1つずつ数える（v − e + f = 2） |
| 整数の性質 | 素因数分解と約数 `#factor` | 因数の木と約数の表。約数の個数・和の公式が表から見える |
| | ユークリッドの互除法 `#euclid` | 長方形から正方形を切りとっていき、最後の正方形 = 最大公約数 |
| | エラトステネスのふるい `#sieve` | 倍数が色つきで消えていく。6列にすると素数の並びが見える |
| | n 進法 `#base` | 玉がたまるとくり上がる。2進法は電球をタップ |
| | 1次不定方程式 `#dioph` | ax + by = c の整数解を格子点で見る。一般解の「ずれ」を矢印で |
| 挑戦 | 10問クイズ `#quiz` | 全分野・分野別。数字は毎回かわる。8問以上で合格のはんこ。最高点を記録 |

## メモ

- フォントは Google Fonts から読み込みます（ネットがなくても動きます。そのときは端末のフォントで表示）。
- スマホでは、上にステージ、下に説明とボタンがならびます。
- ダークモードに自動で対応（黒板の色）。
