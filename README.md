# 数学Aラボ

数学Aの授業で使える、**さわって・動かして・見てわかる** Webアプリです。
`index.html` 1ファイルだけで動きます（インストール不要）。見た目は「分子ラボ3D」とそろえた方眼ノート風です。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/mathematics-a/

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari）で開く
2. 上のタブで分野をえらび、左の一覧から画面をえらぶ
3. まん中のステージで点をドラッグしたり、右のボタン・スライダーを動かしたりする
4. 右の「ポイント」「くわしく」で説明を読む。「⛶ 全画面」でプロジェクター用の大きな表示

URL の最後に `#route` のように付けると、その画面を開いた状態のリンクになります。

## 📖 授業（教科書の順に進む）

11 の単元を、教科書と同じ流れで進めます。

**導入 → 例題 → 類題 → 応用 → 発展**

| 段階 | すること |
|---|---|
| 導入 | そのタイプの問題の紹介と、公式のしくみを図で見る |
| 例題 | 先生といっしょに、図を見ながら 1 ステップずつ解く |
| 類題 | **まず自分で答えをえらぶ** → そのあと図で解説 |
| 応用 | 少しひねった問題。答えをえらんでから図で解説 |
| 発展 | むずかしい問題。答えをえらんでから図で解説 |

- 「次へ ▶」（キーボードの →）で進み、段階の最後で自動的に次の段階へ。
- 画面の上に「いま聞かれていること（問題）」を大きく表示。その下の式は、ステップごとに左から書き足されていきます。
- 図が 1 段ずつかき足され、上の式が左から 1 つずつうまります（式と図の色はそろえてあります）。
- 類題・応用・発展では、答えをえらぶまで解説（と答えの式）はかくれています。わからなければ「解説を見る ▶」。
- 類題・応用・発展では「💡 ヒントを見る」で、おすたびにヒントが1つずつ出ます（2段階）。
- どの段階でも、解いたあとに「📖 それでもわからないときは（くわしい解説）」を開くと、計算のくわしい流れと「よくあるまちがい」が読めます。
- 1 回目にまちがえたときは答えを見せず、ヒントを出して「もう一度」えらべます。
- 終わった段階には ✓、えらんだ答えも記録されます（そのブラウザに保存）。次に開くと、前回の続きの段階から始まります。一覧には進み具合（2/5 など）が出ます。

## ✏️ 例題を入れて図で解説（先生用）

「場合の数・確率・図形の性質・整数の性質」の一覧の上にあります。教科書やプリントの例題を、そのまま数字を入れて図にできます。

1. 問題文の □ に数字を入れる（例：「【6】人から【3】人をえらんで 1 列にならべる」）
2. 上に **問題文** と、数字の入った **公式**（₆P₃ = 6 × 5 × 4 = 120）が出る
3. 「解説をはじめる ▶」で、その数字どおりの図が 1 ステップずつ進む

- 「✏️ 問題文を自分で書く」に教科書の文をはりつけると、それが上に大きく出ます。
- 数字を入れた画面の URL をブックマークすれば、授業ですぐ開けます（例：`#mk-perm?n=6&r=3`）。
- 図にできない数字（大きすぎる・三角形にならない など）は、理由を出して教えます。

| 分野 | 入れられる問題 |
|---|---|
| 場合の数 | 順列、組合せ、両はしが決まった順列、となり合う順列、円順列、円順列（となり合う）、じゅず順列、最短経路（P を通る も）、倍数の個数（ベン図） |
| 確率 | 2 つのサイコロ、袋から 2 個、反復試行、少なくとも 1 回、くじ引きの順番、条件付き確率（表）、検査の陽性 |
| 図形の性質 | 円周角、直径と円周角、円に内接する四角形、方べきの定理（外の点・接線・中の点）、角の二等分線と比 |
| 整数の性質 | 約数の個数と和（素因数 3 種類まで）、互除法、10 進法 → n 進法、n 進法 → 10 進法 |

### 文章題の「場面」と 3D モデル

例題メーカーの多くは、よく文章題に出てくる **場面** を切りかえられます。場面を切りかえると、問題文・単位（人・枚・冊・色…）・説明の言葉・図の中の絵（人・カード・旗・本・料理・玉）が変わります。

- 「🎲 文章題をつくる」で、場面と数字をランダムに選んだ新しい文章題がすぐできます。
- 「🧊 3D」で、その場面の 3D モデルが出ます（ドラッグで回す・ピンチで拡大）。解説を進めると、モデルも動きます（例：選手が表彰台に 1 人ずつ立つ）。
- 3D の部品（three.js）は、ボタンを押したときだけインターネットから読みこみます。

| 問題 | 場面 |
|---|---|
| 順列 | リレーの走順・役をきめる・数字カードで整数・旗のぬり分け・本だな |
| 組合せ | 委員をえらぶ・トッピング・カードを取り出す |
| 両はし／となり合う | 写真のならび・本の両はし／列にならぶ・上巻と下巻 |
| 円順列 | 円卓・輪になって手をつなぐ・回転テーブルの料理（＋となり合う） |
| じゅず順列 | ブレスレット・ネックレス |
| 最短経路 | 碁盤の目の町 |
| 同じものをふくむ順列・重複順列 | 文字カード／人を部屋に入れる・同じ数字を使ってよい整数 |
| 2 つのサイコロ | サイコロ |
| 2 個とり出す | 袋の玉・箱のカード・くじを 2 本・代表をくじで選ぶ |
| 反復試行・少なくとも 1 回 | サイコロ・コイン・シュート |
| くじ引きの順番 | くじ引き・袋から順に取る |
| 条件付き確率 | クラス（めがね）・工場の不良品・部活と通学 |
| 検査の陽性 | 病気の検査・不良品の検査機・迷惑メール判定 |

## 生徒・先生のための機能

**生徒向け（授業）**
- 単元のはじめに「🎯 めあて」、最後に「まとめ」（公式と考え方）。類題・応用・発展が全部できたら「合格」のはんこ。
- 類題を終えたら「🔁 数字をかえて もう1問」で、同じ型の問題を何度でも練習（答え・ヒント・解説も数字に合わせて作られる）。
- 「挑戦 → 学習のきろく・復習」で、全単元の進み具合と結果を一覧。× や − の問題は、その問題だけ もう一度解ける。
- 「余事象」「排反」「互いに素」など点線の用語は、タップすると意味が出る。
- 「↻」で、いまのステップの図の動きを もう一度見られる。

**先生向け**
- 「✏️ 書く」で図に直接書きこめる（赤・青・緑・黒、けす）。電子黒板やタブレットで説明しながら使える。
- 「⛶ 全画面」でも、右下の ◀ ▶（またはキーボードの ← →）で進められる。
- 例題メーカー：「答えをかくす」で、式の先（答え）を見せずに生徒に考えさせられる。
- 例題メーカー：「🔗 リンクをコピー」「☆ この例題を保存」「🖨 印刷」（印刷は問題・式・図だけをきれいに出す）。
- 例題メーカーに「同じものをふくむ順列（例：SUCCESS）」「重複順列」を追加（全 29 種類）。

**みんな**
- 右上の「あA」で文字の大きさ（3 段階）、「🌗」で明るい／暗い画面を切りかえ。

## ひと目でわかる工夫

- どの画面も、ステージの上に **大きな「式の帯」**。上の行が公式、下の行が いまの数字を入れた式です。
- ドラッグできる点は、さわるまで **光って** 知らせます。ステージの左上に「👆 何をすればいいか」を表示。
