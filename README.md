# 数学Aラボ

数学Aの授業で使える、**さわって・動かして・見てわかる** Webアプリです。
`index.html` 1ファイルだけで動きます（インストール不要）。見た目は「分子ラボ3D」とそろえた方眼ノート風です。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/mathematics-a/

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari）で開く
2. 上のタブで分野をえらび、左の一覧から画面をえらぶ
3. まん中のステージで点をドラッグしたり、右のボタン・スライダーを動かしたりする
4. 右の「ポイント」「くわしく」で説明を読む。「⛶ 全画面」でプロジェクター用の大きな表示

URL の最後に `#route` のように付けると、その画面を開いた状態のリンクになります。

## 📮 課題（通信教育で「ここをやっておけ」）

先生がリンクを送るだけで、生徒がひとりで「授業 → 確認テスト」まで進め、結果を先生に送り返せます。

1. **先生：課題をつくる**（課題 → 先生用 → 課題をつくる）
   やってほしい単元にチェック、「授業＋確認テスト」か「授業だけ」、ひとこと・しめきりを入れると、リンクができます。LINE やメールで生徒に送ります。
2. **生徒：リンクを開くだけ**（今日の課題）
   単元ごとに「① 授業 → ② 確認テスト」の進み具合と勉強した時間が出ます。「▶ 次はこれ」の単元を上から順にやります。次にアプリを開いたときも、課題が残っていれば この画面から始まります。
3. **確認テスト**
   数字が毎回かわる 5 問。ヒントなし・1 回勝負で、4 問以上で合格。まちがえた問題は 図の解説で確かめてから、新しい問題で もう一度挑戦できます。
4. **生徒：📤 先生に結果を送る**
   名前を入れておすと、結果の文章とリンクができます（スマホなら そのまま LINE などで送れます）。
5. **先生：結果を見る**
   届いたリンクを開く（または文章ごと はりつける）と、授業の進み・類題〜発展の正解数・テストの点・時間が表になり、「つまずいていそう」な単元も出ます。

6. **🏅 修了証**
   課題を全部クリアすると、生徒の画面に「修了証」ができます（名前・単元・テストの点・クリアした日・完了日・しめきりに間に合ったか）。印刷や PDF 保存ができ、「課題 → 修了証」に たまっていきます。新しい課題が来ても消えません。
   - 修了証には **課題コード**（どの課題か）と **確認コード** が入ります。
   - 先生が「結果を見る」で開くと、確認コードが合っているか（書きかえられていないか）と、自分が出した課題か（課題をつくる で作ったもの）を自動で確かめます。

7. **📦 別の端末に記録を引っこす**（今日の課題・学習のきろく の下）
   スマホ → パソコンのように端末を変えるとき、前の端末で「記録を取り出す」→ 文字を自分に送る → 新しい端末で「読みこむ」。進み具合・テストの点・時間・修了証が移ります。
8. **先生の便利機能**
   「課題をつくる」に これまでに出した課題の一覧（コード・単元・しめきり・リンクの再コピー）。「結果を見る」は 生徒ごとの一覧表（クリア数・修了証の確認）から行をおして くわしく見られます。

※ 記録は生徒の端末（ブラウザ）の中に保存されます。サーバーには送られません。確認コードは「手で書きかえた」ことを見つけるためのもので、パソコンにくわしい人が本気で作れば まねできてしまいます（完全な不正防止ではありません）。

## 🎮 ゲーム（タイムアタック・クラス対戦）

論理表現ラボと同じしくみです。上のメニュー「🎮 ゲーム」から。やるほど 🪙 コインがたまって 段位（10級 → … → 名人）が上がり、バッジ 12 種類がもらえます。

### ⏱ タイムアタック（ひとりで）

- 範囲（全分野／場合の数／確率／図形／整数／授業の類題）と 持ち時間をえらんで「▶ スタート」。答えを どんどんタップ（パソコンなら 1〜4 のキー）。
- **時間がなくなるまで続く**（寿司打のしくみ）：
  - 正解すると **時間がもどる**。問題には むずかしさ ★1〜3 があり、むずかしいほど たくさんもどる（はじめは ★1 +6 秒・★2 +12 秒・★3 +22 秒）。
  - ただし **正解するほど もどる時間が少しずつへる**（1 問ごとに 4% ずつ、最低 2 割まで）ので、いつかは時間切れになります。
  - まちがえると −2 秒、コンボが切れる。5 コンボごとに おまけ +3 秒。時間のバーは 満タンより上には ふえません。
- 持ち時間「おまかせ」は 分野のむずかしさで決まります（全分野・場合の数・図形 90 秒、確率・整数 120 秒、授業の類題 150 秒）。60／90／120／180 秒もえらべます。
- 点数は ★ の数 × 30 点。続けて正解すると **コンボ**。10 コンボごとに ×1.5 → ×2 → … → ×3。
- 目安（ふつうの生徒）：全分野で 2〜3 分・10 問くらい、得意な生徒は 4 分・30 問くらい続きます。
- 結果は「**64 問正解 ≒ 入試の数学A 3 年分**」のように ものさしで出ます。「📣 自慢する」で 結果の文章をコピー（スマホなら LINE などに そのまま送れます）。範囲ごとに ベスト記録が残ります。

### 問題を解く道具（タイムアタック・10問クイズ・授業）

- **図**：図形の問題（円周角・内接四角形・方べき・角の二等分線・重心・正多面体の見取り図）と、最短経路・円周上の点の問題には 図が出ます。授業の類題モードの 円周角・方べきにも図。
- **💡 公式**：その問題で使う公式を出せます。タイムアタックでは 使うと その問題の点と もどる時間が半分。授業では「📐 公式」でその単元の公式の一覧（確認テストでは出ません）。
- **✏️ 計算スペース**：指やペンで書ける方眼のメモ（ペン・けしゴム・1つもどす・ぜんぶけす）。タイムアタックでは 次の問題で自動でけえます。下の **🧮 電卓** には式を入れると答えが出ます（`12*11/2`、`8C3`、`8P3`、`5!`、`2^10`、`3/4+1/6` → 分数のまま `11/12`）。

### 🏆 クラス対戦（リアルタイム）

1. **先生**：🎮 ゲーム → 先生用「🏫 部屋をつくる」。4 けたの **部屋番号** と **QR コード** が出ます（⛶ 全画面にしてプロジェクターに映す）。範囲・持ち時間をえらべます。
2. **生徒**：QR を読みとる か、🎮 ゲームで 部屋番号とニックネームを入れて「参加する」。先生の画面に 名前が 次々ならびます。
3. **先生**：「▶ スタート」。全員の画面で 同時に 3・2・1 → スタート。**全員に同じ問題** が同じ順番で出ます。先生の画面のランキングが リアルタイムで動きます（🔥 はコンボ中）。
4. 正解すると時間がもどるので、終わる時間は 人によってちがいます。先生の画面には「まだプレイ中 ○/○ 人」と出て、終わった人には「おわり」の印。**全員の時間が切れたら**（または先生が「⏹ ここで結果発表」をおしたら）「🎉 結果発表」。1〜3 位にメダル。生徒の画面には「何位 / 何人中」。3 位以内は 🪙 +50。
5. 「▶ 第2回戦 スタート」で 何回でも。「🏆 ハイスコア」タブで その部屋の いちばん良い記録。終わったら「部屋を閉じる」。

40 人でも ランキングは 1 画面に収まります。

### クラス対戦のデータベース

点数を 1 か所に集めるために Google の無料データベース（Firebase Realtime Database）を使います。**はじめから 論理表現ラボと同じデータベースにつながる**ので、ふつうは設定なしで使えます（部屋のデータは `rooms/m〇〇〇〇` に入るので、論理表現ラボの部屋とは ぶつかりません）。
別のデータベースを使うときは「部屋をつくる」の ⚙ に URL を入れてください（作り方は 論理表現ラボの README「クラス対戦の準備」と同じ）。部屋の中身は 部屋番号を知っている人なら見られるので、本名ではなく ニックネームで参加させてください。

## 📖 授業（教科書の順に進む）

11 の単元を、教科書と同じ流れで進めます。

**導入 → 例題 → 類題 → 応用 → 発展**

| 段階 | すること |
|---|---|
| 導入 | そのタイプの問題の紹介と、公式のしくみを図で見る |
| 例題 | 先生といっしょに、図を見ながら 1 ステップずつ解く |
| 類題 | **まず自分で答えをえらぶ** → そのあと図で解説 |
| 応用 | 少しひねった問題。答えをえらんでから図で解説 |
| 発展 | むずかしい問題。答えをえらんでから図で解説 |

- 「次へ ▶」（キーボードの →）で進み、段階の最後で自動的に次の段階へ。
- 画面の上に「いま聞かれていること（問題）」を大きく表示。その下の式は、ステップごとに左から書き足されていきます。
- 図が 1 段ずつかき足され、上の式が左から 1 つずつうまります（式と図の色はそろえてあります）。
- 類題・応用・発展では、答えをえらぶまで解説（と答えの式）はかくれています。わからなければ「解説を見る ▶」。
- 類題・応用・発展では「💡 ヒントを見る」で、おすたびにヒントが1つずつ出ます（2段階）。
- どの段階でも、解いたあとに「📖 それでもわからないときは（くわしい解説）」を開くと、計算のくわしい流れと「よくあるまちがい」が読めます。
- 1 回目にまちがえたときは答えを見せず、ヒントを出して「もう一度」えらべます。
- 終わった段階には ✓、えらんだ答えも記録されます（そのブラウザに保存）。次に開くと、前回の続きの段階から始まります。一覧には進み具合（2/5 など）が出ます。

| 単元 | 導入 | 例題 | 類題 | 応用 | 発展 |
|---|---|---|---|---|---|
| 順列 | ₙPᵣ がかけ算になるわけ | 委員長と副委員長 | リレーの走順 | 両はしが女子 | となり合う |
| 組合せ | なぜ r! でわる？ | そうじ当番 | トッピング | 組に分ける | 最短経路 |
| 集合の要素の個数 | n(A∪B) の公式 | 2 または 5 の倍数 | 3 または 4 の倍数 | どちらでもわり切れない | 最小公倍数に注意 |
| 円順列 | 回して同じものをまとめる | 5 人の円卓 | 6 人の円卓 | 2 人がとなり合う | じゅず順列 |
| 確率の基本 | 同様に確からしい | 袋から 2 個 | 袋から 2 個（類題） | 少なくとも 1 つ | じゃんけん |
| 独立・反復試行 | 確率のかけ算 = 面積 | サイコロ 3 回 | コイン 4 回 | くじを 5 回 | 少なくとも 1 回 |
| 条件付き確率 | 分母がかわる | 部活と通学 | 女子とめがね | くじ引きの順番 | 検査の陽性 |
| 円周角の定理 | 証明 | 中心角から円周角 | 直径と円周角 | 同じ弧をさがす | 内接四角形 |
| 方べきの定理 | 相似で証明 | 長さを求める | 長さ（類題） | 接線の長さ | P が円の中 |
| 約数と最大公約数 | 約数の個数と和 | 36 の約数 | 200 の約数 | 互除法 | 大きな数の互除法 |
| n 進法 | 2 進法のしくみ | 25 → 2 進法 | 50 → 2 進法 | 100 → 3 進法 | 2 進法 → 10 進法 |

URL の最後に `#u-perm`（順列）、`#u-cond`（条件付き確率）のように付けると、その単元を開いたリンクになります。

## ✏️ 例題を入れて図で解説（先生用）

「場合の数・確率・図形の性質・整数の性質」の一覧の上にあります。教科書やプリントの例題を、そのまま数字を入れて図にできます。

1. 問題文の □ に数字を入れる（例：「【6】人から【3】人をえらんで 1 列にならべる」）
2. 上に **問題文** と、数字の入った **公式**（₆P₃ = 6 × 5 × 4 = 120）が出る
3. 「解説をはじめる ▶」で、その数字どおりの図が 1 ステップずつ進む

- 「✏️ 問題文を自分で書く」に教科書の文をはりつけると、それが上に大きく出ます。
- 数字を入れた画面の URL をブックマークすれば、授業ですぐ開けます（例：`#mk-perm?n=6&r=3`）。
- 図にできない数字（大きすぎる・三角形にならない など）は、理由を出して教えます。

| 分野 | 入れられる問題 |
|---|---|
| 場合の数 | 順列、組合せ、両はしが決まった順列、となり合う順列、円順列、円順列（となり合う）、じゅず順列、最短経路（P を通る も）、倍数の個数（ベン図） |
| 確率 | 2 つのサイコロ、袋から 2 個、反復試行、少なくとも 1 回、くじ引きの順番、条件付き確率（表）、検査の陽性 |
| 図形の性質 | 円周角、直径と円周角、円に内接する四角形、方べきの定理（外の点・接線・中の点）、角の二等分線と比 |
| 整数の性質 | 約数の個数と和（素因数 3 種類まで）、互除法、10 進法 → n 進法、n 進法 → 10 進法 |

### 文章題の「場面」と 3D モデル

例題メーカーの多くは、よく文章題に出てくる **場面** を切りかえられます。場面を切りかえると、問題文・単位（人・枚・冊・色…）・説明の言葉・図の中の絵（人・カード・旗・本・料理・玉）が変わります。

- 「🎲 文章題をつくる」で、場面と数字をランダムに選んだ新しい文章題がすぐできます。
- 「🧊 3D」で、その場面の 3D モデルが出ます（ドラッグで回す・ピンチで拡大）。解説を進めると、モデルも動きます（例：選手が表彰台に 1 人ずつ立つ）。
- 3D の部品（three.js）は、ボタンを押したときだけインターネットから読みこみます。

| 問題 | 場面 |
|---|---|
| 順列 | リレーの走順・役をきめる・数字カードで整数・旗のぬり分け・本だな |
| 組合せ | 委員をえらぶ・トッピング・カードを取り出す |
| 両はし／となり合う | 写真のならび・本の両はし／列にならぶ・上巻と下巻 |
| 円順列 | 円卓・輪になって手をつなぐ・回転テーブルの料理（＋となり合う） |
| じゅず順列 | ブレスレット・ネックレス |
| 最短経路 | 碁盤の目の町 |
| 同じものをふくむ順列・重複順列 | 文字カード／人を部屋に入れる・同じ数字を使ってよい整数 |
| 2 つのサイコロ | サイコロ |
| 2 個とり出す | 袋の玉・箱のカード・くじを 2 本・代表をくじで選ぶ |
| 反復試行・少なくとも 1 回 | サイコロ・コイン・シュート |
| くじ引きの順番 | くじ引き・袋から順に取る |
| 条件付き確率 | クラス（めがね）・工場の不良品・部活と通学 |
| 検査の陽性 | 病気の検査・不良品の検査機・迷惑メール判定 |

これまでのスライダーで動かす画面は、一覧の下の「さわって確かめる」にあります。

## レベル（右上の 🌱🌿🌳）

| レベル | ちがい |
|---|---|
| 🌱 やさしい | 類題・確認テストの数が小さい。ヒントが最初から 1 つ出ている |

## 生徒・先生のための機能

**生徒向け（授業）**
- 単元のはじめに「🎯 めあて」、最後に「まとめ」（公式と考え方）。類題・応用・発展が全部できたら「合格」のはんこ。
- 類題を終えたら「🔁 数字をかえて もう1問」で、同じ型の問題を何度でも練習（答え・ヒント・解説も数字に合わせて作られる）。
- 「挑戦 → 学習のきろく・復習」で、全単元の進み具合と結果を一覧。× や − の問題は、その問題だけ もう一度解ける。
- 「余事象」「排反」「互いに素」など点線の用語は、タップすると意味が出る。
- 「↻」で、いまのステップの図の動きを もう一度見られる。

**先生向け**
- 「✏️ 書く」で図に直接書きこめる（赤・青・緑・黒、けす）。電子黒板やタブレットで説明しながら使える。
- 「⛶ 全画面」でも、右下の ◀ ▶（またはキーボードの ← →）で進められる。
- 例題メーカー：「答えをかくす」で、式の先（答え）を見せずに生徒に考えさせられる。
- 例題メーカー：「🔗 リンクをコピー」「☆ この例題を保存」「🖨 印刷」（印刷は問題・式・図だけをきれいに出す）。
- 例題メーカーに「同じものをふくむ順列（例：SUCCESS）」「重複順列」を追加（全 29 種類）。

**みんな**
- 右上の「あA」で文字の大きさ（3 段階）、「🌗」で明るい／暗い画面を切りかえ。

## ひと目でわかる工夫

- どの画面も、ステージの上に **大きな「式の帯」**。上の行が公式、下の行が いまの数字を入れた式です。
- ドラッグできる点は、さわるまで **光って** 知らせます。ステージの左上に「👆 何をすればいいか」を表示。
