# 数学Aラボ

数学Aの授業で使える、**さわって・動かして・見てわかる** Webアプリです。
`index.html` 1ファイルだけで動きます（インストール不要）。見た目は「分子ラボ3D」とそろえた方眼ノート風です。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/mathematics-a/

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari）で開く
2. 上のタブで分野をえらび、左の一覧から画面をえらぶ
3. まん中のステージで点をドラッグしたり、右のボタン・スライダーを動かしたりする
4. 右の「ポイント」「くわしく」で説明を読む。「⛶ 全画面」でプロジェクター用の大きな表示

URL の最後に `#route` のように付けると、その画面を開いた状態のリンクになります。

## 式の意味（✏️）と 文章題（📝）

「次へ ▶」（またはキーボードの →）で 1 ステップずつ進みます。図が 1 段ずつかき足され、**上の式が左から 1 つずつうまっていきます**。式の数字の色と、図の色はそろえてあります（たとえば オレンジの「5」は図のオレンジの部分）。右の「流れ」をタップすると、そのステップへとべます。「自動で進む」で自動再生もできます。

| 式の意味 | 図で見せること |
|---|---|
| 順列 ₙPᵣ `#f-perm` | 席が 1 つずつうまり、5 → 4 → 3 通りとへっていく。樹形図の枝で かけ算になるわけ |
| 組合せ ₙCᵣ `#f-comb` | 60 通りのならびを同じ組ごとに集めると、6 個ずつ 10 列 → ÷ 3! |
| ₙCᵣ = ₙCₙ₋ᵣ `#f-sym` | えらぶ 2 人（オレンジ）と のこす 3 人（青）が 1 対 1 |
| 円順列 `#f-circ` | 24 通りを「回すと同じ」で集めると 4 個ずつ 6 列。A を固定する見方も |
| n(A∪B) `#f-union` | 1〜20 に印をつけ、2 回数えた所を 1 回ひく |
| 余事象 `#f-comp` | 「少なくとも 1 つ」を、反対の 5×5 マスから求める |
| 独立な試行 `#f-indep` | 確率のかけ算 = 長方形の たて × 横 |
| 反復試行 `#f-binom` | ○○×・○×○・×○○ の 3 本の道 × 1 本の確率 |
| 条件付き確率 `#f-cond` | 40 人の図で、分母が「全体」から「男子だけ」にかわる |
| 円周角の定理 `#f-insc` | 直径をひいて二等辺三角形と外角で証明 |
| 約数の個数と和 `#f-div` | 2 の部分 × 3 の部分 の表 → (a+1)(b+1) |

| 文章題 | 図での解き方 |

| じゃんけんのあいこ `#w-janken` | 27 通りの表で「全員同じ」「全員ちがう」 |

## ひと目でわかる工夫

- どの画面も、ステージの上に **大きな「式の帯」**。上の行が公式、下の行が いまの数字を入れた式です。
- ドラッグできる点は、さわるまで **光って** 知らせます。ステージの左上に「👆 何をすればいいか」を表示。

## メモ

- フォントは Google Fonts から読み込みます（ネットがなくても動きます。そのときは端末のフォントで表示）。
- スマホでは、上にステージ、下に説明とボタンがならびます。
- ダークモードに自動で対応（黒板の色）。
